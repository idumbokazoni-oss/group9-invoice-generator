# Small Business Invoice and Receipt Generator

CSC1101 Course Project, Africa University. Group 9, Case 16.

A console program in Python that replaces handwritten invoices.

## Features
- `Item` and `Invoice` classes
- Add and remove items, subtotal calculation
- Percentage discount and tax, final total
- Neat itemised receipt
- Every invoice saved to `invoices.json`; search by invoice number
- Stretch: monthly sales summary

## Run
    python invoice_system.py

## Test
    python test_invoice.py
